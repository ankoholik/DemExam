## КАК ЗАПУСТИТЬ?

### Вписать пароль от вашей базы MySQL в config.py:
   "password": "твой_пароль"
### Создать БД:
   source init_database/create_base.sql
   source init_database/insert_data.sql
### Запустить:
   1. Через run.bat
   2. Через python .\main.py
